# Moodboard — Emily Carter Portfolio

## Feel

Playful, kinetic, mischievous. A visitor should feel instant energy — like landing\
inside a Saturday-morning cartoon studio that also happens to ship professional work.

## Palette

- `--color-canvas: oklch(0.16 0.04 290)` — near-black violet-ink, sets the "cartoon\
  workshop at night" backdrop instead of flat black.
- `--color-ink: oklch(0.97 0.01 290)` — warm off-white for body copy on the dark canvas.
- `--color-accent: oklch(0.78 0.19 130)` — acid/lime green, the single loud accent used\
  on CTAs, underlines and hover states (matches the reference's neon-lime highlight).
- Secondary pops used sparingly on cards only: violet oklch(0.55 0.23 305), coral\
  oklch(0.68 0.19 30), cyan oklch(0.75 0.14 210), gold oklch(0.8 0.15 85) — one per\
  project card so the grid reads like a sticker sheet, never all at once in one section.
- ink-on-canvas and ink-on-accent both clear WCAA AA at these lightness values.

## Type

- Display: **Bricolage Grotesque** (Bunny, weight 800) — chunky, slightly wonky, reads\
  hand-drawn without being a script font. Used for the giant "Hey, I'm EMILY" line.
- Body: **Satoshi** (Bunny, 400/500/700) — clean grotesk for everything else so the\
  page doesn't tip into novelty-font overload.

## References

- Saturday-morning cartoon title cards — thick rounded outlines, drop shadows offset\
  hard right-down, no gradients on type.
- Sticker-sheet skate/streetwear graphics — mismatched pill buttons, tiny stars and\
  scribbles scattered as confetti, everything slightly rotated off-grid.
- VHS/synth-city skyline art (the reference's showreel thumbnail) — silhouette skyline\
  against a gradient sunset, used as the showreel poster art.

## Structure (in order)

1. **Hero** — "Hey, I'm EMILY" + animated character illustration, role tagline, two CTAs\
   (Watch Showreel / View Projects), floating sticker doodles.
2. **Showreel** — a single large video-style panel with play button + skyline art.
3. **Featured Work** — 4 sticker-style project cards, each its own accent color and\
   rotation, tag pill under the title.
4. **Toolkit** (skills) — a horizontal row of software icon chips (not a boring grid —\
   alternating tilt per chip).
5. **About Me** — split panel: doodled self-portrait left, bio + stat chips + CTA right.
6. **Contact / Footer** — big "Let's make something dope" band, socials, email.

## Departures (from the generic SaaS shape)

1. **Hero is illustration-led with a hand-drawn wordmark**, not a text-left/photo-right\
   corporate hero — the character art and lettering ARE the hero, copy is secondary.
2. **Featured Work uses a rotated sticker-card grid with per-card accent colors**\
   instead of uniform three-card-row testimonials/features — each card looks cut out\
   and taped down at a slightly different angle.
